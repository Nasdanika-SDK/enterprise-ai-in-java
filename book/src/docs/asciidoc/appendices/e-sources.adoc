== Sources

Everything this edition was written from.

=== The blueprint

* Anthropic, _Claude Certified Architect, Professional: Exam Guide_, version 1.1, effective December 7, 2026. Section 5 of it is the content outline: seven domains and thirty-nine skills. {exam-guide}
* The certifications page of the Anthropic Partner Academy, where the current exam guides are linked. {certifications}

The exam guide is Anthropic's, and it is the authority on what each skill says.
This book names the domains and the skills as the guide names them and describes each in its own words.

=== Anthropic's public writing

Drawn on for the vocabulary of the first three domains, from the drafting assistant's knowledge of them and not from a fresh reading for this edition.

* "Building effective agents", for the patterns: augmented LLM, workflow, agent.
* "Introducing Contextual Retrieval", for the retrieval skill.
* "Effective context engineering for AI agents", and the documentation of the Claude Developer Platform, for the second domain.
* The Model Context Protocol specification, at modelcontextprotocol.io.

=== Standards behind the vocabulary

* ISO/IEC/IEEE 42010, _Software, systems and enterprise: Architecture description_, for stakeholder, concern, view and viewpoint.
* The TOGAF Standard, for the same vocabulary in an enterprise architecture.
* OpenTelemetry, for traces, logs and metrics, and its semantic conventions for generative AI, which were still changing when this edition was written.
