== Colophon

*Enterprise AI in Java, Objective by Objective: The AI Architect's Domains Through the Nasdanika SDK*

Edition {revnumber}, built on {revdate}.

This book is published in three formats, and each is rebuilt whenever the book changes:

* a web page, {site-url};
* a PDF, {pdf-url};
* an EPUB, {epub-url}.

Its source is at {book-repo} and, as a zip file made from it at each publication, at {sources-url}.

This edition is built on Nasdanika SDK Runtime {runtime-version}.

*Where this edition comes from.*

This edition is the baseline of the book.
An AI assistant, Claude, drafted it on 2026-11-17 from these sources and no others:

* version 1.1 of the exam guide for the Claude Certified Architect, Professional certification, which Anthropic publishes at {certifications};
* Anthropic's public documentation and engineering articles;
* the _Nasdanika SDK Runtime_ book, {runtime-site}, and the _Nasdanika SDK Roadmap_ book, {roadmap-site}, with their repositories;
* the Nasdanika enterprise model, {enterprise-model}, and the architecture repository template, {architecture-template};
* the author's outline of what the book is for and which capabilities of the SDK belong in it.

Nothing in it comes from a preparation course, from study notes, or from an exam.
The author is preparing for the exam as this edition is published, and has not reviewed the edition line by line.
Later editions will carry what he learns and builds, and they can be compared with this one in the history of the repository.

*What it is not.*

This book is not affiliated with, endorsed by or reviewed by Anthropic.
It is not an exam preparation guide, and it has no exam questions in it.
The names of the domains and of the skills in <<part-the-domains>> are those of Anthropic's exam guide, used to say what each section is about.
What each skill asks is given in this book's own words. The exam guide is the authority on its wording, and <<sources>> links to it.
