== The Blueprint Map

The relation that this book is, as two tables.
The first goes from the first semantic domain to the second: each skill of the blueprint, with what it leans on in the SDK.
The second goes from the stakeholder's concerns to the skills that meet them.

Both tables were made from the sections of <<part-the-domains>> for this edition, by a script, and have to be made again when a section changes. Making them in the build is planned.

Read as a whole, the second table says what kind of view this is.
The concerns named most often are ownership and evidence as data, decisions that can be revisited and telemetry from the first line.
The ones named least are data that stays where it is and one platform.
One platform is named least because it is the premise of the whole book and not of any one section.
Otherwise, a concern that few sections name is either one the blueprint does not ask about, or one this edition has not looked at hard enough, and the table does not say which.
